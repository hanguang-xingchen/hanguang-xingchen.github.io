# 2026-08-24 关于个人网站的思考

最近在规划个人站的整体架构，想要做成数据驱动的纯静态站点。

核心思路是把所有配置信息拆成 JSON 文件，HTML 只负责渲染逻辑。这样每次更新数据只需要修改对应的 JSON 文件，不需要碰 HTML 结构。

## 技术选型

- **纯静态**：不需要后端，GitHub Pages / Cloudflare Pages 托管
- **数据格式**：JSON + Markdown
- **渲染方式**：原生 JavaScript + fetch API
- **样式**：复用 psyScale 项目的粉色主题 CSS

## 数据源规划

- `/info/basis.json` — 个人基本信息
- `/info/links.json` — 社交链接和友链
- `/scl90.json` — SCL-90 测评数据
- `/thinking/index.md` — 思考记录索引
